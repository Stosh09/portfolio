# Stosh Ochieng — Portfolio

Full-Stack Software & Systems Engineer portfolio built with **Next.js**, **React**, **TypeScript**, and **Tailwind CSS**.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Content

Update copy, projects, and links in [`lib/content.ts`](lib/content.ts). Static assets live in [`public/`](public/).
